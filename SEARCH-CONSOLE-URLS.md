## How to use this

Submitting the sitemap already queues **every** URL below — you do not need to submit them by hand.
Manual submission (URL Inspection → Request Indexing) just jumps the queue for pages you care about most,
and Google caps it at roughly **10–15 per day**, so work top-down and tick as you go.

1. Search Console → **Sitemaps** → enter `sitemap.xml` → Submit (once, covers everything).
2. Then for the priority pages: paste the URL into the search bar at the top → **Request Indexing**.
